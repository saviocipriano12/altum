# ✅ CHECKLIST DE BOAS PRÁTICAS: Aproveitar 100% da Plataforma

---

## 📋 CHECKLIST DIÁRIO (5-10 minutos)

Faça isso todo dia de manhã:

- [ ] **9:00 AM** - Abra Dashboard
  - [ ] Veja quantos leads novos chegaram
  - [ ] Veja leads "quentes" pra ligar
  - [ ] Veja próximas reuniões do dia

- [ ] **9:10 AM** - Vá ao Inbox
  - [ ] Responda TODAS as mensagens (máximo 1 hora)
  - [ ] Use IA pra perguntas simples
  - [ ] Responda pessoalmente objeções/negociações
  - [ ] Marque como "lido/respondido"

- [ ] **9:45 AM** - Vá ao CRM
  - [ ] Adicione leads novos que chegaram
  - [ ] Atualize etapas de quem respondeu
  - [ ] Defina próximas ações
  - [ ] Agende follow-ups na Agenda

- [ ] **10:15 AM** - Vá ao Pipeline
  - [ ] Veja se arraste cards corretamente
  - [ ] Confira valor total em cada coluna
  - [ ] Identifique gargalos (onde está travando?)

- [ ] **10:45 AM** - Vá ao Relatório
  - [ ] Confira quantos leads tinha meta (compare com dias anteriores)
  - [ ] Veja CPL (custo por lead)
  - [ ] Veja taxa de conversão
  - [ ] Identifique melhor canal

## 📋 CHECKLIST SEMANAL (30-60 minutos)

Faça isso toda sexta-feira:

- [ ] **Análise de Vendas**
  - [ ] Quantos leads chegaram na semana?
  - [ ] Quantos fecharam?
  - [ ] Taxa de conversão?
  - [ ] Compara com semana anterior?

- [ ] **Análise de Canais**
  - [ ] Qual canal trouxe mais leads? (WhatsApp, Google, Instagram, etc)
  - [ ] Qual teve melhor conversão?
  - [ ] Onde quer investir mais?

- [ ] **Limpeza do CRM**
  - [ ] Há leads "perdidos" faz muito tempo? → Mude status para "Perdido"
  - [ ] Há duplicatas? → Mescle leads iguais
  - [ ] Todos têm próxima ação? → Adicione se falta

- [ ] **Análise de IA**
  - [ ] A IA está respondendo bem?
  - [ ] Tem escalações indevidas? → Ajuste guardrails
  - [ ] Tem respostas ruins? → Adicione documentos
  - [ ] Taxa de satisfação está boa?

- [ ] **Planejamento da Próxima Semana**
  - [ ] Preciso de mais leads? → Crie campanha
  - [ ] Preciso acelerar vendas? → Reforce follow-ups
  - [ ] Preciso treinar time? → Estude FAQs

- [ ] **Relatório para Gestor**
  - [ ] Extraia relatório da semana (Menu Relatório → Exportar)
  - [ ] Envie por email pro gestor
  - [ ] Inclua análise: o que funcionou, o que não funcionou

## 📋 CHECKLIST MENSAL (2-3 horas)

  - [ ] Quanto tempo leva cada etapa?
  - [ ] Como acelerar?

- [ ] **Auditoria de IA**
  - [ ] A IA melhorou ou piorou?
  - [ ] Faz sentido ajustar tom?
  - [ ] Faz sentido adicionar novos documentos?

- [ ] **Plano de Ação para Próximo Mês**
  - [ ] Meta de leads?
  - [ ] Meta de conversão?
  - [ ] Meta de receita?
  - [ ] Que canais vou investir?
  - [ ] Que melhorias vou fazer?

## 🎯 CHECKLIST DE SETUP INICIAL (Configure Uma Vez)

Faça isso quando começar:

**SEMANA 1:**

- [ ] **Configurar Empresa**
  - [ ] Menu → Configurações → Empresa
  - [ ] Preencheu nome, CNPJ, logo, descrição?
  - [ ] Conectou WhatsApp?
  - [ ] Conectou outros canais (Instagram, Email)?

- [ ] **Adicionar Time**
  - [ ] Menu → Configurações → Times
  - [ ] Adicionou todos os atendentes?
  - [ ] Definou roles (Admin/Atendente/Gestor)?
  - [ ] Todos receberam convite?

- [ ] **Configurar IA**
  - [ ] Menu → Assistente Altum
  - [ ] Ativou a IA?
  - [ ] Escolheu tom de voz?
  - [ ] Preencheu resumo da empresa?
  - [ ] Definiu objetivo?
  - [ ] Configurou guardrails?
  - [ ] Configurou tópicos de escalação?

**SEMANA 2:**

- [ ] **Adicionar Documentos de IA**
  - [ ] Menu → Base de Conhecimento
  - [ ] Adicionou documentos sobre seus serviços?
  - [ ] Adicionou FAQs?
  - [ ] Adicionou políticas (reembolso, entrega)?
  - [ ] No mínimo 10 documentos adicionados?

- [ ] **Testar IA**
  - [ ] Menu → Perguntar a Altum
  - [ ] Fez 10 testes de perguntas comuns?
  - [ ] Passou em 8+ testes?
  - [ ] Se não, ajustou documentos?

- [ ] **Configurar Integrações**
  - [ ] Menu → Configurações → Integrações
  - [ ] Conectou Google Ads (se usa)?
  - [ ] Conectou Meta Business (se usa)?
  - [ ] Conectou e-commerce (se vende online)?

**SEMANA 3:**

- [ ] **Importar Leads Antigos (opcional)**
  - [ ] Tem lista de clientes/leads antigos?
  - [ ] Importou no CRM?
  - [ ] Atualizou etapas deles?

- [ ] **Treinar Time**
  - [ ] Todos sabem usar Inbox?
  - [ ] Todos sabem usar CRM?
  - [ ] Todos sabem consultar Relatório?

- [ ] **Go Live**
  - [ ] Deixa plataforma em produção
  - [ ] Começa a usar com clientes reais
  - [ ] Monitora performance

## 🚨 CHECKLIST: SINAIS DE ALERTA (Se Algo Tá Errado)

Fique atento:

- [ ] **Atenção:** IA respondendo com taxa de erro > 20%
  - Ação: Adicione mais documentos, revise guardrails

- [ ] **Atenção:** Taxa de conversão caindo
  - Ação: Revise copy, mude tom, teste novo público

- [ ] **Atenção:** Tempo de resposta > 2 horas
  - Ação: Adicione mais atendentes ou automatize com IA

- [ ] **Atenção:** Leads travados em uma etapa
  - Ação: Identifique o problema (preço? processo? documentação?)

- [ ] **Atenção:** Cancelamentos aumentando
  - Ação: Melhore onboarding, suporte, qualidade

- [ ] **Atenção:** Custo de lead aumentando
  - Ação: Revise campanha, mude público, teste novo canal

- [ ] **Atenção:** Time reclamando de plataforma
  - Ação: Treinar, simplificar processo, ouvir feedback

- [ ] **Atenção:** Erros técnicos frequentes
  - Ação: Contatar suporte, documentar bugs

## 💡 CHECKLIST: IDEIAS PARA APROVEITAR MELHOR

Experimentem isso:

- [ ] **Automação de Follow-ups**
  - [ ] Crie regra: "Se lead não respondeu em 2 dias → enviar mensagem"
  - [ ] Use IA para follow-ups automáticos

- [ ] **Templates de Resposta**
  - [ ] Crie templates para respostas comuns
  - [ ] Inbox → use templates pra poupar tempo

- [ ] **Segmentação de Leads**
  - [ ] Separe por: tamanho empresa, setor, interesse, budget
  - [ ] Customize mensagens por segmento

- [ ] **Campanhas Personalizadas**
  - [ ] Campaign 1: Para leads "frios" (primeiro contato)
  - [ ] Campaign 2: Para leads "mornos" (interessados mas ainda pensando)
  - [ ] Campaign 3: Para leads "quentes" (prontos pra fechar)

- [ ] **Scoring de Leads**
  - [ ] Atribua pontos: resposta rápida, abriu email, visitou site, etc
  - [ ] Priorize leads com score alto

- [ ] **Análise Competitiva**
  - [ ] Cada mês, analise 3 concorrentes
  - [ ] O que eles fazem melhor?
  - [ ] O que você faz melhor?

- [ ] **Feedback do Cliente**
  - [ ] Depois de fechar, peça feedback
  - [ ] "Nota de 1-10: como foi trabalhar conosco?"
  - [ ] Use pra melhorar

- [ ] **Análise de Custo-Benefício**
  - [ ] Quanto custa atender cada cliente?
  - [ ] Quanto cada cliente gera de lucro?
  - [ ] Vale a pena manter clientes de baixo ticket?
