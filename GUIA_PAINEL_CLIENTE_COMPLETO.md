## 3️⃣ INBOX / CONVERSAS

### O que é:

É o **WhatsApp da sua empresa**. Todas as mensagens de clientes/leads vêm aqui. É onde você:
- Responde mensagens
- Vê o histórico de conversa
- Usa a IA pra responder
- Anota o contexto

### Como Chegar:

Menu esquerdo → **"Conversas"** (ou "Inbox")

### Como Funciona (Visual):

```
┌──────────────────────────────────────────────────────┐
│  CONVERSAS - INBOX                                   │
├─────────────────────────┬──────────────────────────┤
│                         │                          │

│  (Esquerda)             │  (Direita)              │

│      "Oi, vocês..."     │ @joao_silva             │
│      1 min atrás ●      │ Whatsapp               │
│                         │                          │
│ [👤] Maria Santos       │ ┌──────────────────┐   │
│      "Qual o preço?" ◄  │ │ Oi, vocês fazem? │   │
│      5 min atrás        │ └──────────────────┘   │
│                         │           (10:30)      │
│ [👤] Pedro Oliveira     │                         │
│      "Recebi! Obrigado" │ ┌──────────────────┐   │

│                         │ [Bot 🤖] [📎] [😊] [➤] │
│                         │                          │
└─────────────────────────┴──────────────────────────┘
```

### Passo a Passo: Responder uma Mensagem

**Passo 1: Clique na Conversa**
- Lado esquerdo, clique em um cliente

**Passo 2: Leia o Contexto**
- Veja histórico de mensagens anteriores
- Entenda o que o cliente quer

**Passo 3: Escreva a Resposta**
- No campo "Digitar resposta"
- Escreva sua mensagem
- Pode usar emojis 😊

**Passo 4: Opções de Envio**

```
[Bot 🤖]  ← Deixa a IA responder
[📎]      ← Anexar arquivo/foto
[😊]      ← Adicionar emoji
[➤]       ← ENVIAR
```

**Se usar Bot:**
1. Clica em [Bot 🤖]
2. IA lê a mensagem
3. IA responde automaticamente usando o conhecimento que você configurou
4. Você pode editar antes de enviar
5. Clica [➤] para enviar

**Se responder você:**
1. Digita no campo
2. Clica [➤]
3. Mensagem é enviada pro cliente

### Status das Conversas

Cada conversa pode estar em um status:

| Status | O que significa | O que fazer |
|--------|-----------------|-----------|
| 🟢 **Ativa** | Cliente respondeu recentemente | Responda em até 1 hora |
| 🟡 **Pendente** | Aguardando resposta do cliente | Não precisa fazer nada |
| 🔴 **Urgente** | Cliente mandou várias mensagens | Responda AGORA |
| ⚪ **Encerrada** | Conversa finalizada | Arquivo |

### Dica de Ouro:

**Use a IA quando:**
- Pergunta é comum (preço, prazo)
- Você tem pouco tempo
- Quer qualificar lead

**Responda você mesmo quando:**
- Conversa está quente (cliente muito interessado)
- Precisa de negociação
- Cliente tem dúvida específica sobre contrato

## 5️⃣ PIPELINE / FUNIL

### O que é:

É uma **visualização em Kanban** do CRM. Mostra todos os leads organizados em colunas por etapa.

Tipo um quadro branco onde você arrasta cards.

### Como Chegar:

Menu esquerdo → **"Clientes & Oportunidades"** → **"Kanban"**  
(Ou procure por "Pipeline" / "Funil")

### Como Funciona (Visual):

```
┌──────────────────────────────────────────────────────────────────┐
│  PIPELINE - KANBAN VIEW                                         │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│  [Contato]      [Qualificação]    [Proposta]   [Fechado]       │
│  ──────────────  ──────────────    ──────────  ──────────       │
│                                                                  │
│  ┌─────────────┐ ┌──────────────┐  ┌────────┐  ┌──────────┐   │
│  │ 👤 Maria    │ │ 👤 João      │  │ 👤 Ana │  │ 👤 Pedro │   │
│  │ $?          │ │ $5k          │  │ $10k   │  │ $15k ✓   │   │
│  │ Hoje        │ │ Amanhã       │  │ Junho  │  │ Junho ✓  │   │
│  └─────────────┘ └──────────────┘  └────────┘  └──────────┘   │
│                                                                  │
│  ┌─────────────┐ ┌──────────────┐                               │
│  │ 👤 Cirano   │ │ 👤 Brás      │                               │
│  │ $2k         │ │ $8k          │                               │
│  │ Amanhã      │ │ Próxima sem  │                               │
│  └─────────────┘ └──────────────┘                               │
│                                                                  │
│  📊 RESUMO                                                      │
│  Contato: 2 leads                                              │
│  Qualificação: 2 leads - R$ 13k potencial                      │
│  Proposta: 1 lead - R$ 10k potencial                           │
│  Fechado: 1 lead - R$ 15k ✓ (realizado)                        │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

### Passo a Passo: Usar o Pipeline

**Passo 1: Abra a Seção Pipeline**
- Menu → "Clientes & Oportunidades" → "Kanban"

**Passo 2: Arraste Cards Entre Colunas**
- Quando João responde interessado:
  - Pegue card "João" da coluna "Contato"
  - Arraste pra "Qualificação"
  - Solte
  - Pronto! João foi movido

**Passo 3: Clique em um Card pra Ver Detalhes**
- Clique no card "João"
- Abre a ficha dele
- Você vê dados, notas, histórico

**Passo 4: Use os Valores para Previsão**
- Coluna "Proposta": R$ 10k
  - Significa: tenho R$10k em potencial de venda
  - Se fechar tudo aqui = ganha R$10k
- Coluna "Fechado": R$ 15k ✓
  - Significa: já fechou, é dinheiro confirmado

### Dica: Prever Faturamento

Veja esse pipeline acima:
- Contato: 2 leads (R$ ?) = incerto
- Qualificação: 2 leads (R$ 13k) = 20% chance = R$ 2,6k esperado
- Proposta: 1 lead (R$ 10k) = 70% chance = R$ 7k esperado
- Fechado: 1 lead (R$ 15k) = 100% = R$ 15k confirmado

**Faturamento esperado este mês: R$ 15k (confirmado) + R$ 7k (proposta) = R$ 22k**

Assim você planeja quanto vai ganhar!

### Passo a Passo: Entender os Números

**O que significa cada métrica:**

| Métrica | O que é | Como usar |
|---------|---------|-----------|
| **Leads** | Total de clientes que contataram | Se tem poucos, invista em marketing |
| **Spend** | Quanto gastou em publicidade | Divida por leads pra achar CPL |
| **CPL** | Custo por lead (Spend ÷ Leads) | Quanto custa atrair cada pessoa |
| **Conv.** | Taxa de conversão (Fechados ÷ Leads) | % que vira cliente |
| **Faturamento** | Quanto vendeu | Meta principal |

**Exemplo Prático:**

```
Você tem:
- 100 leads/mês
- Gastou R$ 5.000 em ads
- Fechou 20 contratos
- Faturou R$ 50.000

Métricas:
- CPL = R$ 5.000 ÷ 100 = R$ 50 por lead (bom!)
- Taxa Conversão = 20 ÷ 100 = 20% (ótimo!)
- Ticket Médio = R$ 50.000 ÷ 20 = R$ 2.500 por contrato
- ROI = (R$ 50.000 - R$ 5.000) ÷ R$ 5.000 = 900% (excelente!)
```

### Dica: Comparar Períodos

- Junho vs Maio
- Este trimestre vs trimestre passado
- Este ano vs ano passado

Clique em [📅 Período] e escolha as datas.

## 🏆 DICAS DE OURO: Usar a Plataforma Bem

### 1️⃣ **Use a IA para Tarefas Repetitivas**
- Perguntas sobre preço? IA responde
- Perguntas sobre prazo? IA responde
- Você responde objeções e negocia

### 2️⃣ **Organize seu CRM Diariamente**
- Atualize etapas quando cliente responde
- Adicione notas pra não esquecer contexto
- Defina próxima ação e data

### 3️⃣ **Monitore Pipeline todo dia**
- Veja quantos você tem em cada etapa
- Calcule previsão de faturamento
- Identifique gargalos (onde está travando?)

### 4️⃣ **Responda Rápido (máximo 1 hora)**
- Cliente responde → você responde em 1 hora
- Aumenta 40% a taxa de conversão
- Use notificações do painel pra não esquecer

### 5️⃣ **Agende Follow-ups**
- Toda conversa precisa de próxima ação
- Se cliente não respondeu em 2 dias → follow-up
- Use Agenda pra não esquecer

### 6️⃣ **Revise Relatórios todo dia**
- 5 minutos de leitura
- Sabe se está no ritmo (leads, conversões)
- Identifica o que funciona (canal, tom, etc)

### 7️⃣ **Teste Campanhas Pequeno**
- Antes de enviar pra 1.000, teste pra 100
- Se funcionar, escala
- Se não, ajusta e retesta

### 8️⃣ **Ative Lembretes**
- Reunião agendada → ativa lembrete 15 min antes
- Follow-up marcado → lembrete 1 dia antes
- Nunca mais esquece de nada
