# Agência Altum — fontes externas em revisão

Os agentes neste diretório foram importados de uma fonte externa fixada em commit e permanecem em `review_required_before_activation`. Eles não podem receber ferramentas, dados de clientes ou execução em produção até terem manifesto Altum, permissões, política de custo, avaliação e responsável definidos.
