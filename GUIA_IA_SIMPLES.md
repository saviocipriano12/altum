# 📚 GUIA PRÁTICO: Como Configurar a IA da Altum (Linguagem Fácil)

---

## 🎯 Entender o Básico (30 segundos)

A IA da Altum é como um **vendedor robô**. Ele:
- **Lê** documentos que você adiciona (preços, processos, políticas)
- **Escuta** mensagens de clientes/leads
- **Responde** usando o que você ensinaram + o jeito de ser que você configurou
- **Avisa** quando é algo complicado e passa pro atendente humano

**Objetivo final**: Vender mais, responder 24/7, filtrar curiosos, agendar reuniões.

---

## 🚀 Passo 1: Ir para a Seção de IA (Configurações Principais)

**Local no painel do cliente:**
1. Menu à esquerda → **"Assistente Altum"** (ou **"IA"**)
2. Você vai ver campos para preencher

**O que você vai ver:**

```
☑ IA Ativada?              (sim/não)
📝 Nome do Assistente       (ex: "Altum Bot")
🎤 Tom de Voz             (seleciona um entre várias opções)
📋 Resumo da Empresa      (ex: "Vendemos sites, LPs, automação")
🎯 Objetivo               (ex: "Agendar reunião", "Qualificar leads")
☎️  Telefone Responsável   (seu número de WhatsApp)
```

### ✏️ Como Preencher (Passo 1):

1. **☑ IA Ativada?**
   - Marque ✓ para LIGAR a IA
   - Deixe desmarcado para DESLIGAR temporariamente

2. **📝 Nome do Assistente**
   - Exemplo: `"Altum Bot"` ou `"Atendedor Altum"`
   - Isso aparece para o cliente saber que é um bot

3. **🎤 Tom de Voz** - Escolha UMA opção (mais importante!):
   - `"Casual"` = Fala informal, tipo amigo
   - `"Formal"` = Fala profissional
   - `"Vendedor"` = Agressivo, quer vender (RECOMENDADO PARA ALTUM)
   - `"Técnico"` = Fala de especialista
   - `"Premium"` = Sofisticado, high-ticket

   **👉 Para Altum: Escolha "Vendedor" ou "Premium"**

4. **📋 Resumo da Empresa**
   - Digite num parágrafo o que vocês fazem
   - **Exemplo para Altum:**
     ```
     "Somos a Altum, agência de marketing especializada em engenharia 
     de vendas high-ticket. Oferecemos: desenvolvimento de sites, 
     landing pages otimizadas para conversão, automação de WhatsApp 
     com IA, gestão de tráfego pago e estruturação de negócios digitais. 
     Nossa missão é transformar leads curiosos em clientes pagantes."
     ```

5. **🎯 Objetivo**
   - O que você quer que a IA FAÇA quando alguém manda mensagem?
   - Opções:
     - `"Responder dúvidas"` = Só tira dúvida
     - `"Qualificar e agendar"` = Pergunta se tem orçamento, depois agenda
     - `"Vender"` = Tenta fechar a venda
     - `"Suportar"` = Resolve problemas

   **👉 Para Altum: Escolha "Qualificar e agendar"**

6. **☎️ Telefone Responsável**
   - Seu WhatsApp da empresa (para a IA avisar você quando houver handoff)
   - Exemplo: `+55 31 9 72545430`

## 📚 Passo 2: Adicionar Documentos (Base de Conhecimento)

**Local no painel do cliente:**
- Menu → **"Base de Conhecimento"** (ou **"Conhecimento"**)

**O que você vai ver:**
- Botão: **"+ Adicionar Novo Documento"**
- Aba/abas com: FAQ | Políticas | Produtos & Serviços

### 📋 Tipos de Documentos (Escolha com sabedoria):

#### 1️⃣ **FAQ** (Perguntas Frequentes)
- **Para quê?** Responder dúvidas comuns
- **Exemplo:**
  ```
  Pergunta: Quanto tempo demora para entregar um site?
  Resposta: Entre 3 a 6 semanas, dependendo da complexidade.
  ```

#### 2️⃣ **Políticas**
- **Para quê?** Regras, prazos, formas de pagamento
- **Exemplo:**
  ```
  Política de Entrega: Entregamos em 15 dias úteis.
  Forma de Pagamento: 50% na contratação, 50% na entrega.
  ```

#### 3️⃣ **Produtos & Serviços** (Catálogo)
- **Para quê?** Descrever o que você vende
- **Exemplo:**
  ```
  Serviço: Desenvolvimento de Site
  Preço: A partir de R$ 5.000
  Inclui: Design responsivo, SEO básico, formulário
  Prazo: 3-6 semanas
  ```

### ✏️ Como Adicionar (Passo 2):

**Clique em "+ Adicionar Novo Documento"**

Você vai ver um formulário:

```
Tipo: [Escolha: FAQ / Política / Produto]
Área: [Escolha: Atendimento / Comercial / Entrega / Pagamento]
Título: [Digite um título curto]
Conteúdo: [Descreva em detalhes]
Tags: [Palavras-chave, separadas por vírgula]
```

## 🔐 Passo 3: Guardrails (Regras para a IA NÃO Quebrar)

**O que são?** Limites = coisas que a IA **não pode fazer**.

**Por que?** Para não vender errado, não prometer o que não pode, não envergonhar sua empresa.

### Exemplos de Guardrails para Altum:

```
❌ A IA NÃO PODE:
- Prometer resultado que não temos certeza
- Dar descontos sem autorização
- Comprometer entrega antes de briefing
- Passar número de WhatsApp pessoal
- Falar de concorrentes
- Fazer brincadeiras inadequadas
- Prometer 100% de conversão
```

**Como adicionar?**

Procure no formulário de IA um campo chamado **"Guardrails"** e adicione:

1. `Não prometer resultados garantidos sem dados do cliente`
2. `Não fazer descontos maiores que 15% sem autorização do gestor`
3. `Não compartilhar informações de outros clientes`
4. `Se não souber algo, admitir e passar para humano`

## 🎯 Passo 4: Escalações para Humano (Handoff)

**O que é?** Tópicos que a IA não consegue resolver e precisa passar pro atendente.

### Exemplos de Tópicos para Escalação:

```
- Reclamação sobre projeto anterior
- Pedido de reembolso
- Solicitar alteração em contrato
- Problema técnico complexo
- Negociação de preço
- Dúvida sobre garantia
```

**Como adicionar?**

Procure o campo **"Tópicos de Escalação"** e adicione:

1. `Reclamação ou insatisfação`
2. `Solicitação de reembolso`
3. `Negociação de preço especial`
4. `Problemas técnicos complexos`
5. `Dúvidas sobre contrato ou garantia`

## 📊 Passo 5: Monitorar Performance (Ver como está funcionando)

**Local no painel:**
- Menu → **"IA"** → Aba **"Logs"** ou **"Performance"**

**O que você vai ver:**

| Métrica | O que significa |
|---------|-----------------|
| **Total de Mensagens** | Quantas vezes a IA foi usada |
| **Taxa de Resposta** | % de mensagens que a IA respondeu |
| **Taxa de Handoff** | % que a IA passou pro humano |
| **Tempo Médio de Resposta** | Quanto tempo a IA leva pra responder |
| **Satisfação** | Rating que o cliente deu (⭐⭐⭐⭐⭐) |
| **Documentos Usados** | Quais conhecimentos ela mais usou |

**O que fazer com isso?**

- **Resposta baixa** (< 70%)? Falta documentos. Adicione mais FAQs.
- **Handoff alto** (> 40%)? A IA não sabe responder. Reforce guardrails ou adicione documentos.
- **Satisfação baixa** (< 3 ⭐)? Tom ou resposta está ruim. Mude o tom de voz ou revise documentos.

## ✅ Checklist: Configuração Completa

### Antes de ligar a IA, verifique:

- [ ] IA está ativada? ✓
- [ ] Nome do assistente está preenchido?
- [ ] Tom de voz escolhido (recomendação: "Vendedor")?
- [ ] Resumo da empresa descreve bem o negócio?
- [ ] Objetivo está claro (agendar reunião)?
- [ ] Telefone responsável está correto?
- [ ] Adicionou **pelo menos 3 documentos** (1 FAQ, 1 Política, 1 Produto)?
- [ ] Cada documento tem **título, conteúdo e tags** claros?
- [ ] Guardrails foram configurados?
- [ ] Tópicos de escalação estão definidos?

### Antes de Usar com Clientes Reais:

- [ ] Teste a IA com **5 perguntas típicas** (ex: "Quanto custa?", "Quanto tempo?")
- [ ] Verifique se as respostas fazem sentido
- [ ] Se resposta estiver ruim, revise o documento relacionado
- [ ] Teste a escalação (fale algo que deve passar para humano)
- [ ] Ajuste tom se necessário

## 🎓 Dicas de Ouro

### 1. **Documentos Claros = Respostas Boas**
   - Escreva como se fosse explicar para um amigo
   - Evite jargão técnico
   - Seja específico (preço, prazo, processo)

### 2. **Tags São Importantes**
   - Use tags que descrevem o documento
   - Exemplo: `site, design, preço:5000, comercial`
   - Ajuda a IA a encontrar a informação certa

### 3. **Tom de Voz Faz Diferença**
   - "Formal" = Mais distante
   - "Vendedor" = Mais agressivo, convence
   - "Premium" = Sofisticado, confiança
   - **Para agência: Use "Vendedor" ou "Premium"**

### 4. **Menos é Mais**
   - Não coloque 500 documentos de uma vez
   - Comece com 20-30 principais
   - Vá adicionando conforme vê o que falta

### 5. **Revise Regularmente**
   - A cada 2 semanas, veja os logs
   - Se tem resposta ruim, ajuste o documento
   - Se tem escalação que não deveria, revise guardrails

## 🐛 Problemas Comuns e Soluções

| Problema | Solução |
|----------|---------|
| IA não está respondendo | Verifique se está ativada (☑) |
| Respostas erradas | Adicione mais documentos ou revise os existentes |
| IA passa demais pro humano | Aumente documentos, reduza guardrails muito rígidos |
| Responde muito formal | Mude o tom para "Casual" ou "Vendedor" |
| Não menciona preço | Adicione documento de "Catálogo" com preços claros |
| Fala de coisas que não sabe | Configure melhor os guardrails |
